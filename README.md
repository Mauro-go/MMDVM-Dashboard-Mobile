# MMDVM Dashboard Mobile
<img src="https://github.com/user-attachments/assets/280588f1-c8de-4f82-b3d0-7d4e4032e83e" width="250" alt="MMDVM Dashboard Mobile Screenshot" />

Android companion app for [MMDVM Dashboard MQTT Multi](https://github.com/Mauro-go/MMDVM-Dashboard-MQTT-Multi).

## 🇮🇹 Italiano

**MMDVM Dashboard Mobile** è un'applicazione Android per monitorare i ripetitori collegati a MMDVM Dashboard MQTT Multi.

### Funzionalità
- Monitoraggio dei ripetitori e dell'attività radio.
- Selezione dei nodi in configurazioni multi-ripetitore.
- Collegamento tramite API della dashboard.
- Supporto MQTT opzionale.
- Interfaccia in italiano e inglese, con selezione automatica o manuale della lingua.
- Tema scuro e icona personalizzata.

### Installazione

Scarica l'APK dalla sezione **Releases**, installalo sul telefono Android e configura l'indirizzo della tua dashboard.

## 🇬🇧 English

**MMDVM Dashboard Mobile** is an Android companion application for monitoring repeaters connected to MMDVM Dashboard MQTT Multi.

### Features
- Repeater monitoring and radio activity.
- Node selection for multi-repeater installations.
- Dashboard API connectivity.
- Optional MQTT support.
- Italian and English interface with automatic or manual language selection.
- Dark theme and custom app icon.

### Installation

Download the APK from **Releases**, install it on your Android phone, and configure your dashboard address.
